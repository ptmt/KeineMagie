- **≥1000 CSS px:** месячная сетка с прежней навигацией и подробностями.
- **<1000 CSS px:** одна полоса высотой 30 px, семь квадратов с буквами дней недели, отметкой сегодня и подробностями по нажатию. Не уменьшенная/свёрнутая месячная сетка. Месячные кнопки удаляются из DOM, итог и легенда скрыты.
